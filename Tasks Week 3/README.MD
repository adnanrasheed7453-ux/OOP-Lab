# C++ OOP Tasks

This repository contains a collection of C++ Object-Oriented Programming (OOP) tasks completed as part of my university coursework.

The tasks focus on classes, objects, functions, arrays of objects, passing objects to functions, returning objects from functions, references, and copy constructors.

## Topics Covered

* Classes and Objects
* Passing Objects by Reference
* Passing Objects by Const Reference
* Returning Objects from Functions
* Arrays of Objects
* Functions with Object Arrays
* Copy Constructors
* Basic Data Handling using C++

## Project Tasks

### Question 1 – Update a Student Record

Demonstrates passing an object by reference to a function and updating its marks.

**Concepts:**

* Classes and Objects
* Reference Parameters
* Modifying Object Data

### Question 2 – Display an Employee Without Changing It

Demonstrates passing an object using a constant reference so that the function can display its data without modifying it.

**Concepts:**

* Const Reference
* Object Parameters
* Data Display

### Question 3 – Create and Return a Product

Demonstrates creating an object inside a function and returning that object to the calling function.

**Concepts:**

* Object Creation
* Functions Returning Objects
* Classes and Objects

### Question 4 – Process an Account and Return the Updated Copy

Demonstrates passing an object by value, modifying the copy, and returning the updated object while keeping the original object unchanged.

**Concepts:**

* Pass by Value
* Returning Objects
* Object Copying

### Question 5 – Add Grace Marks to Every Student

Demonstrates using an array of objects and passing it to a function to modify the marks of multiple students.

**Concepts:**

* Arrays of Objects
* Functions
* Loops
* Object Data Manipulation

### Question 6 – Fill Student Records Using a Function

Demonstrates using a function to fill multiple student objects with names and marks.

**Concepts:**

* Arrays of Objects
* Functions
* Loops
* Class Members

### Question 7 – Copy a Mobile Record

Demonstrates the use of a copy constructor to create a new object from an existing object.

**Concepts:**

* Constructors
* Copy Constructors
* Private Data Members
* Object Copying
