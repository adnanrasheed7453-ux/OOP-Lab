# Lab 4 – C++ OOP Projects

## Description
This lab contains two C++ projects developed using Object-Oriented Programming (OOP) concepts. The projects are Bank Account Management System and Car Rental System.

## Task 1: Bank Account Management System
This project manages basic bank account operations, including depositing money, withdrawing money, displaying account details, and managing account balances.

### Features
- Create and manage bank accounts
- Deposit and withdraw money
- Display account information
- Manage multiple accounts

## Task 2: Car Rental System
This project manages car information, speed, and rental charges. It allows users to store car details, control speed, and calculate rental costs according to the number of days.

### Features
- Store car brand and model
- Accelerate and brake a car
- Manage car speed
- Calculate rental charges
- Display car information
- Manage multiple cars

## OOP Concepts Used
- Classes and Objects
- Constructors and Copy Constructor
- Encapsulation
- Getters and Setters
- Passing Objects to Functions
- Static and Dynamic Arrays
- Dynamic Memory Allocation using `new` and `delete`
- Destructor

## Programming Language
C++

## Project Files
1. `Bank_Account_Management_System.cpp`
2. `Car_Rental_System.cpp`

## Conclusion
These projects demonstrate the practical implementation of Object-Oriented Programming concepts in C++. They provide an understanding of classes, objects, constructors, encapsulation, arrays, and dynamic memory management.
